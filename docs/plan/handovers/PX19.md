# PX19 — Work / Issues relationship

- **Status:** CONDITIONAL PASS
- **Decision:** Work is the generalized, human-first issue/task object. Attempts are optional execution records behind Work; a separate duplicated Issues database is not introduced.

## What changed
- Work now supports body, repository context and assignee through a compatibility-safe detail record.
- Open/closed filtering, issue-like detail route, conversation/comments and reopen/close flow.
- Linked Attempts and PR counts are visible but not required to understand or use Work.
- A normal bug/feature can be created and discussed with zero Agents.

## Gate
Static product/API gate passes; normal-environment Trestle gate remains.
