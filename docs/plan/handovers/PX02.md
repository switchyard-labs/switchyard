# PX2 — Owner/repository namespace + migration design

- **Status:** CONDITIONAL PASS — workspace implementation is complete; the live deployment gate still needs one user-owned and one org-owned real Artifacts repository registered through the new owner/repo layer.
- **Objective:** establish stable owner/repository identity without destructive physical Git renames.
- **What changed:** new `owner_namespaces` and `repository_meta` coordination models, explicit repository registration API, canonical owner/repo read APIs, canonical browser route parsing, user/org namespace collision enforcement, legacy compatibility retained.
- **What deliberately did not change:** existing Artifacts repositories were not renamed or bulk-claimed; old `/api/repos` and `repo.html?name=` paths continue to work.
- **Regression evidence:** Go sources parse/gofmt cleanly, Nift rebuild succeeds, and browser JS passes `node --check`. Full `go test ./...`/`go vet ./...` could not run in this offline artifact runner because the workspace requires Go 1.26 and uncached module/toolchain downloads are blocked; the tests are included for the normal development environment.
