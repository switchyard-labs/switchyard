# PX9 — Interactive Agent-to-draft UX
- **Status:** CONDITIONAL PASS (implementation/race contract static-gated; live deterministic runner race gate requires normal Switchyard stack).
- Added a distinct `agent-propose` draft endpoint. It runs the common Agent substrate against an explicit draft revision, re-reads after execution, and CAS-applies only if the draft did not move.
- Interactive mode **never commits Git**. It updates recoverable draft state, shows the diff, and leaves Commit as an explicit human action.
- A newer human save wins over a stale Agent result; stale proposals return `draft_stale` and preserve the newer draft.
- Draft records retain the last Agent execution/prompt; a later human commit records mixed editor+Agent provenance without claiming the Agent solely authored the commit.
- Formal Attempt mode is preserved separately for autonomous work.

**Gate:** `experiments/product-ux/px9/static_gate.sh` PASS. Live runner/CAS race test remains required on the normal environment.
