# PX23 — Public demo environment

- **Status:** CONDITIONAL PASS
- **Objective:** make a safe public staging mode possible without exposing private coordination/admin state.

## What changed
- `SWITCHYARD_DEMO_MODE=true` introduces read-only anonymous guest browsing.
- Demo repository list is restricted to canonical Switchyard repositories marked public; legacy flat Artifacts routes are rejected for guests.
- Anonymous demo mutations are denied at middleware before handlers.
- Demo banner, reset helper and deployment/security contract added.

## Still required before public exposure
HTTPS/reverse proxy, rate/abuse limits, dedicated demo credentials, curated data reset automation and a clean-browser external gate. No domain/resources were provisioned here.
