# PX5 — Language detection + shared syntax highlighting foundation

- **Status:** PASS (offline fixture gate)
- **Objective:** establish one dependency-free language identity/token layer for repository view, Markdown fences, diff/review presentation, and editor status.

## What changed
- Added `public/assets/js/code-surface.js`: shared language registry/detection and safe lightweight read-only highlighter.
- Initial languages: Go, C/C++, Rust, JavaScript, TypeScript, JSX/TSX, HTML, CSS, JSON, YAML, TOML, Markdown, shell, Python, SQL, Nift, Strut, plaintext fallback.
- Added shared non-blue syntax tokens and line-anchor presentation to `theme.css`.
- Large/unknown content safely degrades to escaped plaintext.

## Evidence
`node experiments/product-ux/px5/code_surface_test.js` → PASS across the registry plus token/line rendering.

## Deliberately not changed
The CM6 editor language extensions are addressed in PX8. PX5 establishes the shared language identities and read-only presentation substrate first.

## Security
All highlighter output escapes source text before returning HTML/token spans; unknown files do not execute content.

## Impact
PX6 source browsing and PX7 Markdown fences consume this layer; PX8 displays the same language identities in editor status.
