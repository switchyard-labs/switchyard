## Architecture decisions (this checkpoint)
1. **Ref substrate:** non-force git push is the CAS primitive; stale writers are
   rejected by Git ("fetch first"); `git ls-remote` (auth) is the read path;
   **force-push is policy-gated and never used by the integration path**
   (E1).
2. **Draft concurrency:** per-file three-way merge via `git merge-file`;
   rc=0 apply, rc≠0 surface contention; conservative on adjacent edits; no
   last-writer-wins (E2/E3).
3. **Draft semantics:** Save = synchronous durable revision; autosave = debounced
   sync; one snapshot + base, no history; expiry enforced (E2).
4. **Secret path:** resolution-only plaintext via scoped 0600 file; no secret in
   child output/env; expiry at resolution; full impl deferred to CP6 (E4).

- Adjacent-line draft edits can surface as conservative conflicts (accepted).
- Force-push bypasses git CAS — must be policy/permission-gated everywhere.
- E2/E4 spikes are stand-ins; full implementation and real latency measurement
  belong to CP10 (draft backend) and CP6 (secret delivery).
