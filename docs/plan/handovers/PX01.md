# PX1 — Information architecture + URL/domain model

- **Status:** PASS
- **Objective:** lock the simple Git-host mental model before visual implementation.
- **What changed:** `docs/plan/product-ia.md` now defines global navigation, repository tabs, user/org/profile routes, owner/repository canonical URLs, compatibility routes and progressive disclosure rules.
- **What deliberately did not change:** no backend routes or frontend navigation were migrated yet; PX2 establishes durable ownership identity and PX4 implements navigation.
- **Key decision:** user and organization slugs share one owner namespace; canonical repositories are `/{owner}/{repo}` while physical Artifacts names remain backend implementation detail.
