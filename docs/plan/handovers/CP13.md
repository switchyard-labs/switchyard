## What was proven
A new Artifacts repo seeded with **Switchyard's own source** (cmd/, internal/,
docs/, go.mod — 58 files) is operated on end-to-end by Switchyard:

1. Work item created; an Attempt opened on an isolated branch (`df1`).
2. A **durable workflow** runs the `implementer` Agent (deterministic adapter —
   Dogfood 3's real-LLM leg remains bounded on CP6's credential condition, via
   the identical substrate) which edits `docs/dogfood.md` + `ATTEMPT.md`; the
   deterministic `check` passes; the `review` approves.
3. Review produces structured findings on Switchyard's own change.
4. A PR is opened; **preview integration** is clean.
5. The **Integration Queue** integrates the Switchyard PR into canonical
   (`done`).
6. Canonical now carries the dogfood change (docs/dogfood.md on main).
7. The full provenance chain is queryable: work → attempt → pr → ref_updates →
   events.
