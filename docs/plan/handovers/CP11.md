# Checkpoint 11 handover

- **Checkpoint:** CP11 — Needs Attention + escalation
- **Status:** PASS (gate: `experiments/cp11/cp11_gate.sh`, live 9/9)

## What changed
- `internal/app/attention.go`:
  - `GET /api/attention` — aggregates everything needing a decision: attempts
    in `conflict`, integration queue items `blocked`, workflow runs
    `waiting_approval`, and open `error` findings.
  - `POST /api/attention/{kind}/{id}/escalate` — assembles a **self-contained
    decision packet** for a conflicted attempt: target, repo, branch, base,
    the conflicting files with base + source versions, recorded findings, and
    suggested resolutions (take_ours / take_theirs / three_way). No history
    reconstruction required to decide.
  - `GET /api/escalations`, `POST /api/escalations/{id}/decide` — applies a
    human decision through the existing repair paths: take_ours / take_theirs /
    three_way (writes the chosen file versions onto the attempt branch via the
    shared ref substrate, closes findings, marks the attempt resolved),
    queue requeue, workflow approve.
  - No-op decisions (e.g. take_theirs where the source already carries the
    chosen content) are recorded and the attempt marked resolved without a
    spurious commit.

## Gate evidence (live, 9/9)
1. Same-file contention: A integrates; B is blocked by the queue and the
   attempt is parked in `conflict`.
2. `GET /api/attention` aggregates attempt_conflict + queue_blocked + open
   error findings (6 items).
3. Escalation produces a self-contained packet with the conflicting files
   (ATTEMPT.md, shared.txt) including base + source versions.
4. A human decides `take_ours` → attempt resolved (2 files), the blocked queue
   item re-queued → **B integrates** (`done`).
5. A workflow waiting for approval appears in attention; an `approve` decision
   completes it.

## Security notes
Decisions are attributed (decided_by) and recorded on the escalation;
resolution goes through the same role-scoped, provenance-bearing ref substrate.
The packet contains repository content (not credentials).

## Impact on later checkpoints
- CP12 org policy can drive which decisions require escalation / who may decide.
- CP13 dogfooding: escalation is how human oversight enters the loop.
