# PX7 — Markdown/README/image renderer
- **Status:** PASS (renderer/security fixture); live repo image gate remains part of batch revalidation.
- Added a raw-HTML-denying Markdown renderer with headings/anchors, lists, tables, blockquotes, fenced highlighted code, links and images.
- `javascript:`/`data:` destinations are rejected; source text is escaped.
- Repository roots automatically render README with documented root-first precedence (`README.md`, `README.markdown`, `README`, then `docs/README.md`).
- Relative links/images resolve against README path/ref through the repository content API; detected MIME types make image delivery viable.
- Renderer is deliberately reusable for PX11/PX13 profile READMEs.

**Gate:** `node experiments/product-ux/px7/markdown_test.js` PASS including malicious raw HTML/link fixture.
