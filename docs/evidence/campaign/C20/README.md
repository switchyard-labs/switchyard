# C20 — repository workbench

The actual local application and SQLite Trestle instance connect to the disposable Cloudflare Artifacts repository `codex-actions-probe-20261003`. Editor validation uses only its `editor-c20` branch; application source was not pushed.

The browser committed the preserved human draft (`3494eb4`), dragged `docs/architecture.md` into `validation/editor`, reviewed the explicit Git commit dialog and verified the relocated file and content at commit `49f8e2f`. It created a JavaScript file through the explorer, typed its content, exercised undo/redo, saved a draft and explicitly committed. Server probes separately rejected an outdated SHA with `branch_moved` and deletion containing an active saved draft with `affected_draft_present`. Repository content search returned a real match in `src/routes.mjs` at line 2, column 17; clicking it selected that position.

Save remains distinct from Commit. Revision CAS protects human saves and rejects an Agent proposal against R when the human has saved R+1; a delayed-runner race regression exercises that sequence. Committed draft records retain revision metadata on reload, without replacing committed Git content with an old draft. Per-file editor states preserve undo/selection/scroll while open; session storage preserves paths, active file and expanded directories, never document contents. Saved contents live in Trestle. Directory creation starts a `.gitkeep` draft because Git does not store empty directories.

Gantry Core is a real pinned Go dependency, used for bounded search compilation and binary detection. Its editor package offers text operations, not a browser tree, tab manager, CodeMirror renderer or authorization API. Warden's workbench architecture and interactions were studied and independently adapted; reference repositories were not edited. Switchyard retains repository authorization, immutable Git reads, explicit commit/CAS and server draft fences. There is no interactive terminal. CodeMirror language/search/history dependencies are locked and reproducibly bundled under `ui/editor`; third-party licenses are included there.

Search is server-side at an immutable SHA: 30 seconds, 100 scanned files, 1 MiB per file, 20 MiB aggregate, 200 results, explicit skipped/truncated indicators. The tree is bounded to 1,000 directories, 10,000 files and depth 32. Moves/deletes require a nonempty commit message, exact branch SHA and regular Git files, with collision/path/mode validation. Moves preserve executable mode. These bounds intentionally exclude binary, symlink and submodule editing. File operations check all users' active saved drafts; a draft created concurrently remains durable and its stale Git base must be reconciled.

Interactive proposal transport is tested with the configured deterministic runner; this is not evidence of intelligent external Agent execution. Runtime executor configuration and full product responsive certification remain later gates. No shared deployment or standard Workers Builds preview was performed.
